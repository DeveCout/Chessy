# Chessy
Chessy is a personnal project about creating an automatic playing chess board. It will include the .step files to create pieces in epoxy, the board with his CoreXY and the step to creat it yourself
/!\ The project is still in developpment. I did'nt finished it yet so I need to add advice, ajust my files etc.../!\

## Presentation

Chessy is a chessboard wich use a coreXY and an electro-magnet to move the epoxy pieces on top of the board. The board is copperplated with the square made of tinted epoxy.
I tried to have most my tools Open sourced. Here the actual list of the tools I used :
- Bambulab P1P
- FreeCAD : An opensource software to create technical mechanical part and 3D print them
- Parts :
  - PLA Filament Black (Printed most part)
  - 2 Nema motor (CoreXY)
  - Ball bearings (Core XY)
  - Belt GT2 x2 (Core XY)
  - Silicone to create the epoxy mold from 3D printed parts
  - Epoxy and compatible dye.
  - Magnet for the pieces (help the electro magnet to "attach" to them)


I will ajust this list when all the project is done (dimensions, etc...)

### STEP 1 :

The first step is to create the pieces, CoreXY, and the rest in FreeCAD. I will need to create the assembly to make sure everything can move freely and as Intended.

### STEP 2 :

Print the pieces, create the silicon mold and mold the epoxy.

Advice I learned the wrong way :
- After printing the pieces, it's important to polish them until they're "shiny". Otherwise the epoxy pieces will have the imperfection of the 3D print.
  Wich remove the "glass" effect.
- PUT GLOVES WHEN YOU MAKE SILICONE AND EPOXY. In my experience, silicone is the worst substance to remove from your hands, it's gluey et don't get away with water + soap.
  If somehow you have it on your hand, don't worry t should'nt be toxic (depend on the product used ! Be careful). You can remove it with paper towel.
- If you create a mold for the pieces, be awar that 3D print mold (contenant of the overall final mold) is a pain to detach. The horizontals "stripes" of the 3D print can make it really hard to remove.
  My tips is to create a mold in multiple part. Forget about a "vase" like mold. Either you will break the contenant, either you'll destroy the silicon mold. I will give my model for it.
- If you want to create your own mold for your own pieces : Plastic can float on top of silicon. So keep that in mind when making it.
